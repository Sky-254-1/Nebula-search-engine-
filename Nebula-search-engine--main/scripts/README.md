# Nebula Search - Deployment Scripts

This directory contains PowerShell scripts to automate the deployment and verification of Nebula Search Engine.

## Prerequisites

Before using these scripts, ensure you have installed:

- **PowerShell 5.1+** (included with Windows 10/11)
- **Docker Desktop** - https://www.docker.com/products/docker-desktop/
- **Python 3.11+** - https://www.python.org/downloads/ (for running tests)
- **Node.js 20+** - https://nodejs.org/en/download/ (for running tests)

## Scripts

### 1. `generate-secrets.ps1`

Generates cryptographically secure random secrets for production deployment.

**Usage:**
```powershell
# Display secrets only
.\generate-secrets.ps1

# Generate and update .env.production automatically
.\generate-secrets.ps1 -UpdateEnvFile
```

**Generated Secrets:**
- `JWT_SECRET` - 32 characters (for JWT token signing)
- `SESSION_SECRET` - 32 characters (for session management)
- `ENCRYPTION_KEY` - 32 characters (for data encryption)
- `POSTGRES_PASSWORD` - 24 characters (database password)
- `MINIO_ROOT_PASSWORD` - 24 characters (storage password)
- `GRAFANA_ADMIN_PASSWORD` - 24 characters (monitoring password)

### 2. `generate-favicon.ps1`

Generates a placeholder `favicon.ico` file from the SVG design.

**Usage:**
```powershell
.\generate-favicon.ps1
```

**Note:** This creates a minimal placeholder. For production, convert `frontend/public/favicon.svg` to ICO using:
- Online: https://convertio.co/svg-ico/
- ImageMagick: `magick convert favicon.svg favicon.ico`
- Inkscape: `inkscape --export-type=ico --export-filename=favicon.ico favicon.svg`

### 3. `deploy.ps1`

Automates the complete deployment process using Docker Compose.

**Usage:**
```powershell
# Full deployment
.\deploy.ps1

# Skip building images (use existing images)
.\deploy.ps1 -SkipBuild

# Skip tests (if already run)
.\deploy.ps1 -SkipTests
```

**What it does:**
1. Verifies Docker is running
2. Checks for `.env.production` (creates from `.env.example` if missing)
3. Generates `favicon.ico` if missing
4. Pulls latest base images
5. Builds application images
6. Starts all services
7. Waits for services to be healthy
8. Runs database migrations
9. Displays service URLs

### 4. `verify-deployment.ps1`

Verifies that all services are running and healthy after deployment.

**Usage:**
```powershell
# Verify with default 30-second timeout
.\verify-deployment.ps1

# Verify with custom timeout
.\verify-deployment.ps1 -Timeout 60
```

**What it checks:**
- Docker is running
- All containers are running
- Container health status
- Backend health endpoint
- API health endpoint
- Frontend health endpoint
- Auth API responsiveness
- Search API authentication
- MinIO storage health

## Quick Start

### First-Time Deployment

```powershell
# 1. Generate secrets
.\generate-secrets.ps1 -UpdateEnvFile

# 2. Deploy
.\deploy.ps1

# 3. Verify
.\verify-deployment.ps1
```

### Redeploy After Code Changes

```powershell
# Rebuild and restart
.\deploy.ps1

# Verify
.\verify-deployment.ps1
```

## Troubleshooting

### Docker not running
```powershell
# Start Docker Desktop
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

### Port conflicts
```powershell
# Check what's using ports
netstat -ano | findstr :80
netstat -ano | findstr :443
netstat -ano | findstr :8000
netstat -ano | findstr :3000
```

### View logs
```powershell
# All services
docker compose -f ..\docker-compose.prod.yml logs -f

# Specific service
docker compose -f ..\docker-compose.prod.yml logs -f backend
docker compose -f ..\docker-compose.prod.yml logs -f frontend
```

### Restart services
```powershell
docker compose -f ..\docker-compose.prod.yml restart
```

### Rebuild from scratch
```powershell
docker compose -f ..\docker-compose.prod.yml down
.\deploy.ps1 -SkipTests
```

## Environment Variables

Required secrets are generated by `generate-secrets.ps1`. For manual configuration, see `.env.example`.

**Critical secrets (must be set before production):**
- `JWT_SECRET` - Min 32 characters
- `POSTGRES_PASSWORD` - Strong password
- `MINIO_ROOT_PASSWORD` - Strong password
- `GRAFANA_ADMIN_PASSWORD` - Strong password
- `SESSION_SECRET` - Min 32 characters
- `ENCRYPTION_KEY` - Min 32 characters

## Security Notes

- Never commit `.env.production` to version control
- Store secrets in a secure password manager
- Rotate secrets regularly (every 90 days)
- Use different secrets for each environment (dev/staging/prod)
- Enable SSL/TLS in production (configure `docker/nginx.prod.conf`)
