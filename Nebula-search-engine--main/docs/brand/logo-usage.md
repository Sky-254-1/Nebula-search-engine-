# Logo Usage Rules

## Clear Space

The logo requires **clear space** equal to **1× the icon height** on all sides.

### ✅ Correct
```
[LOGO]     (1x space)
(1x space) (LOGO) (1x space)
           (1x space)
```

### ❌ Incorrect
```
[LOGO]NO SPACE (text too close)
```

## Minimum Sizes

| Usage | Minimum | Why |
|-------|---------|-----|
| Favicon | 16×16 | Below 16px, details blur |
| UI Icon | 24×24 | Neural nodes illegible |
| Header | 32×32 | Brand identity visible |
| Marketing | 48×48 | Full detail visible |

## Color Rules

### ✅ Correct
- Use the brand gradient: `#7c5cfc` → `#3b82f6` → `#6366f1`
- Use dark cosmic background: `#0b0c10`
- Use white text on dark backgrounds

### ❌ Incorrect
- ❌ Solid single-color logos (always gradient)
- ❌ Light backgrounds (use `#0b0c10`)
- ❌ Black on dark (use white or light gray)

## Orientation

### ✅ Correct
- **Primary**: 45° angle for handle, centered
- **Responsive**: Maintain aspect ratio

### ❌ Incorrect
- ❌ Stretched or squished
- ❌ Rotated 90° (handle becomes vertical)
- ❌ Cropped (cut off handle or nodes)

## Placement

### ✅ Correct
- Top-left corner (standard)
- Centered above text (marketing)
- In navigation (mobile app)

### ❌ Incorrect
- ❌ Bottom-right (non-standard)
- ❌ Behind other elements
- ❌ Overlapping text

## Incorrect Usage Examples

### 1. Wrong Colors
```
❌ Red gradient logo
❌ Blue only logo
❌ Green accent colors
```

### 2. Wrong Background
```
❌ White background (use dark)
❌ Bright pattern background
❌ Clashing gradient background
```

### 3. Wrong Orientation
```
❌ Handle pointing up/down (not 45°)
❌ Logo rotated 180°
❌ Handle at 90° angle
```

### 4. Wrong Size
```
❌ 8×8 favicon (too small)
❌ Stretched 2× width (distorted)
❌ Cropped (missing parts)
```

## Authorized Variations

### 1. Inverted (for light backgrounds only)
```
✓ Dark background: #0b0c10
✓ Mark: White gradient
✓ Only in exceptional cases
```

### 2. Icon-only
```
✓ For social media avatars
✓ For mobile app icons
✓ Keep minimum 192×192
```

### 3. Monochrome
```
✓ Black only (dark backgrounds)
✓ White only (light backgrounds)
✓ Use sparingly (not primary)
```
